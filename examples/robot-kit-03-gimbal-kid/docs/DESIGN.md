# robot-kit-03-pendulum (desk)

Folder name `robot-kit-03-gimbal-kid` is historical. This is **not** a closed gimbal joystick.

Narrative only. The machine contract is `PRINT_SPEC.yaml`.

Kid-friendly **inverted pendulum**: a cream/white stick with a red ball on a horizontal SG90 shaft, sweeping a vertical plane. You knock it; the Super Mini tries to keep it up. **No lid, no collar.** Rounded plate / fairing around the servo. `03` on the front.

Canonical copy: `../robot-kit-03-pendulum-kid/`. Wall-mount: `../robot-kit-03-pendulum-wall-kid/`.

Print: plate, stick, knob. Buy MCU, one SG90, battery.
