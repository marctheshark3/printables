# robot-kit-02-gripper

Narrative only. The machine contract is `PRINT_SPEC.yaml`.

Numbered 02 servo gripper: MCU on deck, SG90/9g at the base, short blocky distal link (8 mm thick, not a 9g SCARA tower / old 14.7 mm wrap), wrist is a second SG90 house, red printed fingers. Gold `robot_kit.scad` only has an SG90 pocket, so distal links stay short and blocky instead of inventing a smaller-servo well. Do not print MCU, servos, or battery.

Shared kit library: `src/lib/robot_kit.scad`.
