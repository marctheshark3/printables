# Narrative notes (optional)

Markdown may explain decisions. It cannot override `docs/PRINT_SPEC.yaml`.

```markdown
# <part-name>

Purpose, never-list, and photo notes belong here.

Machine facts (class, backend, dimensions, shells, fit, drainage, orientation)
live only in PRINT_SPEC.yaml.
```

Fill `templates/PRINT_SPEC.yaml` first. Run `validate_print_spec.py` before CAD.
