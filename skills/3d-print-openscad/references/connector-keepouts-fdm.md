# FDM connector keepouts

Single home for default port window sizes. Class skills reference this file;
they must not copy a second table.

Windows are plug-overmold envelopes plus slack, in millimetres. Clearance is
still declared per side in `PRINT_SPEC.yaml` when a fit is critical.

| Port | Window W×H mm | Basis |
|------|---------------|--------|
| USB-C | 13.5 × 9.0 | Plug ~12.4×8.3 + slack |
| micro-USB Type-B | 13.0 × 8.5 | Plug ~10.6×8.5 + slack |
| microSD | 16.0 × 3.5 | Card + path |
| STEMMA QT pair | 22 × 9 | JST-SH pair |
| STEMMA single | 10 × 8 | one JST-SH |
| RESET poke | Ø6.5–7 | face |
